# Campaign review packet

Export a single editable Markdown packet for review:

```bash
genforge-marketing radar campaign-review-packet --campaign campaigns/bookmark-launch --output output/bookmark-review-packet.md
```

The packet combines campaign metadata, dashboard readiness and blockers, human review items, the creative brief and storyboard, plus a decision checklist for production approval. It is read-only with respect to the campaign: it does not mark approval or publish content.
