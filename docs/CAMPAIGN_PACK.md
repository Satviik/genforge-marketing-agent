# Campaign Pack

Assemble the original creative brief and Claude-ready Markdown handoff in one offline command. Optional reference breakdown, timeline, and frame notes can be included as JSON evidence. No model or paid API is called.

## CLI

```bash
genforge-marketing radar campaign-pack --product "Custom bookmark" --description "Personalized gift" --objective inquiries --duration 20 --breakdown output/creative-breakdown.json --timeline output/reel-timeline.json --visual-notes output/frame-visual-notes.json --brief-output output/campaign-brief.json --handoff-output output/claude-handoff.md
```

Both artifacts are drafts. Review product claims, creative direction, and source adaptation notes before production.
