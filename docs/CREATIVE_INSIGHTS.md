# Creative Insights

Produce exploratory rankings and controlled-test suggestions from the creative feedback report. The engine summarizes observed metrics and suggests experiments, but does not claim causality, statistical significance, or virality prediction.

## Command

```bash
genforge-marketing radar creative-insights --report output/creative-feedback-report.json --output output/creative-insights.json
```

Use this as a planning aid. Comparisons are meaningful only when post age, audience, spend, product and posting conditions are reasonably comparable.
